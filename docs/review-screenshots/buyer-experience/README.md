# Buyer experience screenshots

Captured from the running local Vite app on 2026-11-02 at desktop 1440px and mobile 390px viewports. Each listed route has desktop and mobile screenshots:

- `home`: `/` — the buyer marketplace is the default entry point.
- `products`: `/marketplace?search=linen#products` — product discovery/search route.
- `shops`: `/shops` — shop directory.
- `product-detail`: seller-scoped product detail route.
- `storefront`: existing public seller storefront route.
- `order-tracking`: guest order tracking route.

The local backend API was not running during capture. Marketplace and shop pages therefore show their API error/empty states; product detail and storefront show their unavailable states, and the tracking page shows an invalid-link error. The screenshots demonstrate page routing, responsive layout, navigation, and error states, not populated real inventory or a completed order. Mobile captures measured document width equal to the 390px viewport; desktop captures had no width greater than 1440px.
